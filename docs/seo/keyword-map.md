# Persian Keyword Map — Pendar Nim Rokh Clinic (Qom)

- Created: 2026-10-28
- Site: https://pendarqom.ir
- Scope: local commercial and informational queries for the current Astro content model
- Status: working map — keyword targets are hypotheses to validate in Search Console
- Related: site SEO audit, 2026-10-28

## Method and limits

- Live Google spot checks were run on 2026-10-28 for 7 queries:
  `کلینیک روانشناسی قم`، `زوج درمانی در قم`، `مشاوره کودک و نوجوان در قم`،
  `هزینه مشاوره روانشناسی در قم`، `مشاوره پیش از ازدواج در قم`،
  `روانشناس خانم در قم`، `تست روانشناسی در قم`.
- No search-volume data, Search Console data, or rank-tracking data was available.
  Priorities below are based on commercial intent, observed SERP composition, and
  services the clinic actually offers. Do not treat them as volume estimates.
- The SERP snapshot is a point-in-time observation; Google results vary by location,
  device, and personalization.

## SERP observations

1. Head terms are dominated by medical directories, not clinic sites:
   doctoreto, doctor-yab, nobat.ir, ravandarman, behtarino, achareh, kardarmanitv.
2. Clinic sites can appear (e.g. rohanmoshavereh.ir), but not consistently for broad terms.
3. Person listings on directories rank for name queries; `محمد مصباحی` already appears
   on doctor-yab for marriage counseling in Qom. Person-name queries are the fastest
   entry point.
4. Cost queries are dominated by national tariff pages plus local directory pages.
   A local fee page with real ranges can still win long-tail cost queries.
5. Long-tail condition, gender, pre-marital, testing, and online-therapy queries are
   weaker on directories — that is where the site should compete first.

## Strategy in one paragraph

Win long-tail local, person-name, and condition queries first; use directories and maps
as distribution channels for head terms; keep one page per search intent and never create
a thin duplicate page for a keyword the homepage or a service page already owns.

Priority legend:

- **P0** — optimize an existing URL now (highest commercial value)
- **P1** — create or substantially expand within 90 days
- **P2** — supporting page, optimize after P0/P1
- **P3** — opportunistic / low demand

## 5. Persian variant normalization

Use one spelling in titles and H1s. Do not create URLs for variants.

| Use in titles/H1 | Variants users type |
|---|---|
| روانشناس | روان شناس |
| روان‌درمانی | روان درمانی |
| زوج‌درمانی | زوج درمانی |
| خانواده‌درمانی | خانواده درمانی |
| بیش‌فعالی | بیش فعالی |
| مشاوره | مشاورهٔ |
| آنلاین | انلاین |
| تست | آزمون |
| کلینیک | مرکز مشاوره / دفتر روانشناسی |
| خانم | زن / بانو |
| هزینه | تعرفه / قیمت |

Also normalize Arabic `ي`/`ك` to Persian `ی`/`ک` before creating slugs. Persian digits
in titles, Latin digits in URLs.

## 6. Cannibalization rules

1. Homepage owns «کلینیک روانشناسی در قم» and «روانشناس در قم». Never create a separate
   «بهترین روانشناس قم» page.
2. Each service page owns exactly one service head term. Do not repeat
   «کلینیک روانشناسی قم» in every service title.
3. Therapist pages own person names only; service head terms belong to service pages.
4. Pre-marital counseling is separate from couples therapy: different intent, different page.
5. Assessment owns «تست روانشناسی»; child testing is a section inside it until it has
   enough unique content.
6. Conditions (anxiety, depression, OCD) stay as articles until they can support a
   600+ word service page with a distinct therapist assignment.

## 7. Do not target

| Keyword / topic | Reason |
|---|---|
| روانپزشک قم | The clinic provides psychology services, not psychiatric/medication services. Only cover it in the comparison article. |
| نوروفیدبک، هیپنوتیزم، بازی‌درمانی، اوتیسم، ترک اعتیاد | Not confirmed services. Do not create pages for them. |
| درمان قطعی اضطراب / افسردگی | Cure claims are unsafe and damage YMYL trust. |
| بهترین روانشناس قم (as a separate URL) | Keep it as a secondary query on the homepage; a separate page would cannibalize and look promotional. |
| English keywords | Therapists list Persian only; the audience is Persian-speaking. |
| مشاوره تحصیلی (as a service page) | Only a mentioned problem area; use an article/section unless the clinic confirms it as a service. |
| بیمه / تحت پوشش بیمه | Do not claim coverage until the owner confirms which insurers are accepted. |

## 10. 90-day rollout

1. **Week 1:** fix the license placeholder, verify Search Console, enable analytics,
   audit NAP consistency.
2. **Weeks 1–3:** rewrite titles, H1s, and meta for homepage + 6 services + 8 therapists;
   create the pre-marital page.
3. **Weeks 3–6:** claim/complete directories, Google Business Profile, Neshan, Balad;
   add the female-therapist section; launch the fees page if approved; create the
   online-therapy page.
4. **Weeks 6–12:** publish 8–10 articles in the order above; add internal links;
   refresh one page per month.
5. **Monthly:** review Search Console queries containing «قم»; improve pages ranking
   5–20 first; drop keywords that never generate impressions.

## 11. Measurement and validation

- Verify the domain in Search Console (DNS TXT through Cloudflare) before judging
  any target in this map.
- Use Search Console queries and impressions as the source of truth for volumes after
  2–3 months. Third-party Persian volume estimates are often unreliable.
- Track conversions from phone and WhatsApp. Add UTM parameters to WhatsApp and
  Instagram links; ask reception to log how each caller found the clinic.
- Re-run the 7 SERP checks quarterly; directory dominance can change.
